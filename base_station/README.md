# Base Station

This directory contains the software for the Surf-Cam base station.

The base station receives GPS and sensor data from the Raspberry Pi transmitter through an ExpressLRS (ELRS) wireless connection.

The received data is processed and can be displayed on a dashboard for testing purposes, the data is used to monitor the surfer's position, speed, and orientation helping the camera accurately track them.

## Hardware
- Windows PC or laptop
- HappyModel ES900TX
- USB connection to the ELRS transmitter
