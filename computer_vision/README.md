# Computer Vision

This directory contains the AI image recognition and tracking software for Surf-Cam.

The computer vision system uses machine learning to detect and track surfers in video footage.

The goal is to combine visual tracking with telemetry data from the Raspberry Pi transmitter to identify and follow a specific surfer, even when they temporarily disappear behind waves.

## Features
- Surfer detection using YOLO26
- Video processing and object tracking
- Future integration with GPS telemetry
