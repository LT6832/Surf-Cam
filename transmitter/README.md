# Raspberry Pi Transmitter

This directory contains the software for the
Raspberry Pi Zero 2 W telemetry transmitter.

The transmitter collects GPS, accelerometer,
gyroscope, magnetometer, and barometer data
from the BerryGPS-IMU v4 module.

Sensor data is transmitted wirelessly to the
base station using ExpressLRS (ELRS).

## Hardware
- Raspberry Pi Zero 2 W
- BerryGPS-IMU v4
- HappyModel ES900RX
