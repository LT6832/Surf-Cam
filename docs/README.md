# Documentation

This directory contains technical documentation for the Surf-Cam project.

The documentation will explain how to assemble, configure, and operate the hardware and software components.

## Planned Documentation
- Hardware components and specifications
- Raspberry Pi wiring diagrams
- ExpressLRS (ELRS) configuration
- Sensor calibration procedures
- Transmitter installation
- Base station installation
- System architecture diagrams

Documentation will be added as development progresses.
