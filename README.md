# Surf Cam

An open-source surf camera project that uses computer vision to analyze surf video.

## Goals
- Record surf sessions using a Raspberry Pi or laptop
- Use a computer vision model to detect and track surfers in the footage
- Train the model on more powerful hardware, then run it in the field on a portable device (RTX 3050 tablet)

## Why
Existing options like SOLOSHOT and Surf Eye are closed systems. This project aims to be more flexible and open, built on open-source software.
